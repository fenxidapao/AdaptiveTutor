# 计算机组成原理 · 指令系统与寻址方式

指令是计算机能识别并执行的基本命令。指令系统（ISA）是软硬件界面，规定了所有指令的格式、操作码、寻址方式与功能。

## 指令格式

一条指令通常由**操作码（opcode）**与**地址码**组成。操作码指明做什么；地址码给出操作数或操作数地址。按地址码个数分为：
- 零地址指令（如栈操作，操作数隐含在栈顶）
- 一地址指令（单目运算或 ACC 隐含累加）
- 二地址指令（两操作数，结果常回写其一）
- 三地址指令（两源一目的，结果不破坏源）

指令长度可与机器字长相等（定长指令），也可变长（按操作码扩展，节省空间但取指复杂）。定长操作码译码简单；变长常用**操作码扩展技术**在地址数少的指令中挪用地址位表示更多操作码。

## 寻址方式

寻址方式决定操作数有效地址（EA）如何形成。

- **立即寻址**：操作数直接在指令中（#data），取指即得，速度快但不便修改。
- **直接寻址**：指令给出操作数**有效地址**，访存一次取数；地址范围受指令地址字段长度限制。
- **间接寻址**：指令给出的是**地址的地址**（指针），需多次访存；可扩大寻址范围，便于间接访问。
- **寄存器寻址**：操作数在寄存器中，无需访存，速度快。
- **寄存器间接寻址**：寄存器中存的是内存地址，访存一次取数。
- **基址寻址**：EA = 基址寄存器 + 形式地址，基址不变、形式地址可变，便于程序浮动与多道程序（重定位）。
- **变址寻址**：EA = 变址寄存器 + 形式地址，变址可变、形式地址不变，便于数组/循环（变址自增遍历）。
- **相对寻址**：EA = PC + 形式地址（位移量），用于转移指令，便于程序位置无关（浮动代码）。
- **堆栈寻址**：操作数隐含在栈顶，SP 指向栈顶，用于表达式求值与过程调用。

## 操作数类型与大小端

常见操作数类型：地址、数值（定点/浮点）、字符、逻辑。多字节数据在内存中的存放有**大端（高位在低地址）**与**小端（低位在低地址）**之分，跨机器通信需注意字节序转换。

## CISC 与 RISC

- **CISC**（复杂指令集）：指令功能强、条数多、变长、寻址方式丰富，典型 x86；译码复杂、CPI 较高。
- **RISC**（精简指令集）：指令少而简单、定长、单周期为主、load/store 架构（仅访存指令碰内存）、大量寄存器、靠编译器优化，典型 ARM/MIPS；流水线效率高。

## 指令的执行

取指 → 译码 → 取操作数 → 执行 → 写回。现代 CPU 通过**流水线**让多条指令的不同阶段重叠，提高吞吐；但遇到数据相关、控制相关（转移）会引冲突，需旁路（forwarding）、分支预测等技术缓解。

## 特权指令与系统调用

指令分**用户态/核心态**可执行两类：特权指令（如 I/O、关中断、改基址）仅核心态可用，防止用户程序破坏系统；应用程序经**系统调用（trap 陷入）**请求内核服务，陷入后切到核心态执行。
