# 计算机网络 · IP 地址、子网与路由

网络层核心任务是把分组从源主机经若干路由器转发到目的主机，关键是**IP 寻址**与**路由选择**。

## IP 地址

IPv4 地址为 32 位，点分十进制表示（如 192.168.1.1）。由**网络号 + 主机号**两部分构成，主机号全 0 为网络地址、全 1 为广播地址，均不可分配给主机。

### 分类地址（已淘汰，仅作理解）

- A 类：0 开头，8 位网络号，大型网络。
- B 类：10 开头，16 位网络号。
- C 类：110 开头，24 位网络号，小型网络。
- D 类：1110 开头，组播地址；E 类保留。

分类法浪费严重，已被**无分类域间路由（CIDR）**取代。

## 子网划分与 CIDR

CIDR 用"IP/前缀长度"表示，如 `192.168.1.0/24` 表示前 24 位为网络前缀。子网掩码是前缀对应的 32 位掩码（/24 → 255.255.255.0）。通过将主机位借给网络位，可将大网划分为若干小子网，**子网号 = IP 与子网掩码按位与**。路由聚合（超网）则用更短前缀合并多条路由，减小路由表。

### 划分子网要点

给定网络与所需子网数/每子网主机数，确定借位数与掩码；每个子网可用主机数 = 2^主机位 − 2（减去网络号与广播地址）。VLSM（变长子网掩码）允许不同子网用不同掩码以提高利用率。

## 路由选择

路由器根据**路由表**转发：匹配目的网络前缀（最长前缀匹配），经相应接口送出。

### 静态路由 vs 动态路由

- **静态路由**：手工配置，简单、无开销，不适应拓扑变化。
- **动态路由**：路由器间交换路由信息自动更新，适应变化但有协议开销。

### 路由协议分类

- **IGP（域内）**：RIP（距离矢量，跳数，≤15 跳）、OSPF（链路状态，Dijkstra 算最短路径，收敛快）、IS-IS。
- **EGP（域间）**：BGP（路径矢量，基于策略，互联网骨干）。

### 距离矢量与链路状态

- **距离矢量**（RIP）：每节点仅知"到各目的的距离与下一跳"，周期向邻居通告整张表，可能产生**慢收敛/路由环路**（用水平分割、毒性逆转缓解）。
- **链路状态**（OSPF）：各节点获全网信拓扑，独立用 Dijkstra 计算最短路径树，无路由环路、收敛快，但存储与计算开销大。

## ARP 与 ICMP

- **ARP**（地址解析协议）：已知 IP 求 MAC，广播询问、单播应答，结果缓存于 ARP 表。
- **ICMP**（网际控制报文协议）：传递差错与控制信息，如 Echo 请求/应答（ping）、目的不可达、TTL 超时（traceroute 利用）。

## IP 分片与 MTU

链路层有最大帧长（MTU），IP 数据报超过 MTU 时需**分片**，在目的端重组；IPv4 由路由器或源端分片，IPv6 不允许中间路由器分片（靠路径 MTU 发现）。标识、标志、片偏移字段用于分片与重组。

## IPv6 简述

128 位地址，解决 IPv4 耗尽；取消校验和与分片（端到端），简化首部，地址用冒号十六进制。过渡技术：双栈、隧道（如 6to4）、NAT64。
