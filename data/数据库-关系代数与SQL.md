# 数据库 · 关系代数与 SQL

关系模型用二维表（关系）表示数据：关系（表）、属性（列）、元组（行）、域（属性取值范围）。主键唯一标识元组；外键引用另一关系的主键以维持参照完整性。

## 关系代数基本运算

关系代数是 SQL 的理论基础，以关系为操作对象，结果仍为关系。

### 一元运算

- **选择 σ**（selection）：按条件筛选**行**。σ_{条件}(R)，如 σ_{age>20}(Student)。
- **投影 π**（projection）：选取若干**列**并去重。π_{列}(R)，如 π_{Sname}(Student)。投影会消除重复元组。

### 集合运算

要求参与运算的关系**同构**（属性个数与域兼容）：
- **并 ∪**：属于 R 或 S 的元组。
- **差 −**：属于 R 但不属于 S 的元组。
- **交 ∩**：可经差运算表示，∩R S = R − (R − S)。
- **笛卡尔积 ×**：R 的每元组与 S 的每元组拼接，属性数为两者之和，元组数为两数之积；会产生大量无意义组合，通常配合选择使用。

### 连接运算

- **θ 连接**（theta-join）：R ⋈_{条件} S = σ_{条件}(R × S)，按条件对两关系拼接筛选。
- **自然连接 ⋈**：在**同名同域属性**上相等连接并去重重复列，是最常用连接。自然连接是 θ 连接（等值于公共属性）加投影去重的特例。
- **外连接**：保留一侧或两侧在连接中未匹配上的元组，缺失属性填 NULL——左外连接（保留左表全部）、右外连接、全外连接。

### 除运算 ÷

适用于"查询至少包含所有…"类问题。R ÷ S 结果为满足"其与 S 的笛卡尔积包含于 R"的属性组合。直观：从 R 中找出在 S 所有取值上都出现的那些分组键。

## 关系代数与 SQL 的对应

| 关系代数 | SQL 子句 |
|---|---|
| σ_{条件} | WHERE / HAVING |
| π_{列} | SELECT 列 |
| × / ⋈ | FROM A, B / A JOIN B ON … |
| ∪ | UNION |
| − | EXCEPT（或 NOT EXISTS 子查询） |
| ÷ | 用 NOT EXISTS 双重否定表达 |

## SQL 查询基本结构

```sql
SELECT [DISTINCT] 列
FROM 表 [JOIN 表 ON 条件]
WHERE 行条件
GROUP BY 分组列
HAVING 组条件
ORDER BY 列 [ASC|DESC];
```

执行逻辑顺序：FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY。WHERE 在分组前过滤单行，HAVING 在分组后过滤组。

## 聚集函数与分组

COUNT、SUM、AVG、MAX、MIN 对一组值聚合。与 GROUP BY 配合：按某列分组后对各组分别聚合。SELECT 中非聚集列必须出现在 GROUP BY 中。

## 嵌套子查询

子查询嵌套在 WHERE / FROM / SELECT 中：
- **IN 子查询**：判断值是否属于子查询结果集。
- **比较子查询**（> ANY / < ALL）：与子查询结果逐个或整体比较。
- **相关子查询**：子查询引用外层元组属性，对外层每行重新执行，常用于表达"至少""不存在"等（也是表达除运算的手段）。
- **EXISTS**：判断子查询是否返回至少一行，常与 NOT EXISTS 配合表达"不存在…"的除法语义。

## 视图

视图是由查询定义的逻辑表（虚表），不存储数据，提供安全性与简化复杂查询。CREATE VIEW 定义，对视图的更新需满足一定约束（通常要求视图来自单表且不含聚集/去重）。
