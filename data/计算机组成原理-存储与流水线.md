# 计算机组成原理：存储层次与指令流水线

## 1. 存储层次

- 速度由快到慢、容量由小到大依次为：**寄存器 → Cache → 主存（内存） → 辅存（磁盘）**。
- **局部性原理**是存储层次有效的根本依据：**时间局部性**（刚访问过的单元很可能再次被访问）、**空间局部性**（被访问单元附近的单元很可能也被访问）。
- **Cache 命中**指所需数据已在 Cache 中；**未命中（缺失）**则需到主存取，带来缺失代价（miss penalty）。

## 2. Cache 映射方式

- **全相联映射**：主存块可放入任意 Cache 行；命中率高，但查找（比对标记）慢。
- **直接映射**：每个主存块固定对应唯一 Cache 行；查找快，但冲突缺失多（不同块争用同一行）。
- **组相联映射**：Cache 分行成组，组内全相联；是直接映射与全相联的折中（如 4 路组相联）。
- **替换策略**：LRU（最近最少使用）、FIFO、随机。常用**写策略**：写直达（同时写 Cache 与主存）、写回（仅当脏块被替换时才写回主存）。

## 3. 指令周期与流水线

- 经典五段指令周期：**取指（IF）→ 译码（ID）→ 执行（EX）→ 访存（MEM）→ 写回（WB）**。
- **指令流水线**让多条指令的不同阶段重叠执行，从而提高吞吐率；理想加速比约等于流水段数。
- **流水线相关（冲突）**：
  - **结构相关**：硬件资源冲突，如单端口存储器同时被取指与访存争用。
  - **数据相关**：后一条指令用到前一条尚未写回的结果，其中 **RAW（写后读）**最常见；可用**转发 / 旁路（forwarding）**缓解，必要时插入气泡（空操作）等待。
  - **控制相关**：转移指令改变 PC 导致后续预取失效；可用分支预测、延迟槽缓解。
- **吞吐率**指单位时间内完成的指令数；实际受相关与停顿影响，低于理想值。
