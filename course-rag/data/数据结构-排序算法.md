# 数据结构 · 排序算法

排序是将一组无序记录按关键字递增或递减排列的操作。评价排序算法的核心维度：时间复杂度（最好/平均/最坏）、空间复杂度、稳定性、是否原地。

## 排序算法的分类

按是否基于比较分为两类：
- **比较排序**：通过元素间比较决定次序，决策树下界为 O(n log n)，如快排、归并、堆排、冒泡、插入、选择。
- **非比较排序**：利用关键字分布特征，可突破 O(n log n)，如计数排序、基数排序、桶排序，但通常需要关键字范围有限。

按稳定性划分：
- **稳定排序**：相等关键字的记录排序后相对次序不变，如冒泡、插入、归并、计数、基数。
- **不稳定排序**：可能改变相等元素的相对次序，如快排、堆排、选择、希尔。

原地性：插入、冒泡、选择、快排、堆排可原地（O(1) 额外空间）；归并、计数、基数通常需要额外空间。

## 冒泡排序（Bubble Sort）

重复遍历序列，比较相邻元素，若逆序则交换，每趟把当前最大元素"浮"到末尾。稳定，原地。最好 O(n)（已排序加标志位提前退出），平均与最坏 O(n^2)，空间 O(1)。

## 插入排序（Insertion Sort）

将每个元素插入到前面已排序子序列的适当位置，类似整理手牌。稳定，原地。最好 O(n)（基本有序），平均与最坏 O(n^2)。对小规模或基本有序数据效率高，常作为快排/归并的递归底限优化。

## 选择排序（Selection Sort）

每趟从未排序区选最小（或最大）元素放到已排序区末尾。不稳定（如 [2,2,1] 交换会打乱相等元素次序），原地，无论最好最坏均 O(n^2)。实际性能通常不如插入排序。

## 快速排序（Quick Sort）

分治思想：选一个 pivot，将序列划分成"小于 pivot"和"大于 pivot"两部分，递归排序子区间。平均 O(n log n)，最坏 O(n^2)（每次划分极不均衡，如已排序且 pivot 取端点）。通常不稳定。原地划分版本空间 O(log n)（递归栈）。工程实现常随机化 pivot 或三数取中来规避最坏情况，并在小数组切换插入排序。

## 归并排序（Merge Sort）

分治：将序列对半分，递归排序两半，再合并两个有序序列。稳定，时间稳定 O(n log n)（与输入无关），但需要 O(n) 额外空间。_merge 操作是核心：用双指针比较两个有序数组头元素，依次取小者输出。

## 堆排序（Heap Sort）

利用大顶堆（或小顶堆）：先建堆 O(n)，再反复取堆顶（极值）并调整堆 O(n log n)。不稳定，原地（O(1) 额外空间），最坏也是 O(n log n)，适合对最坏情况有要求的场景。但缓存局部性较差，常数因子常大于快排。

## 计数排序（Counting Sort）

非比较排序：统计每个关键字出现次数，计算前缀和得到每个元素的最终位置。要求关键字为非负整数且范围 k 不大。时间 O(n + k)，空间 O(n + k)，稳定。是基数排序的基础。

## 基数排序（Radix Sort）

非比较排序：按关键字低位到高位（或高位到低位）逐趟用稳定排序（通常计数排序）分配收集。时间 O(d·(n + k))，d 为位数。稳定，适合整数或定长字符串。

## 排序算法对比小结

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定 |
|---|---|---|---|---|
| 冒泡 | O(n^2) | O(n^2) | O(1) | 是 |
| 插入 | O(n^2) | O(n^2) | O(1) | 是 |
| 选择 | O(n^2) | O(n^2) | O(1) | 否 |
| 快排 | O(n log n) | O(n^2) | O(log n) | 否 |
| 归并 | O(n log n) | O(n log n) | O(n) | 是 |
| 堆排 | O(n log n) | O(n log n) | O(1) | 否 |
| 计数 | O(n+k) | O(n+k) | O(n+k) | 是 |
| 基数 | O(d(n+k)) | O(d(n+k)) | O(n+k) | 是 |

选择排序算法的经验准则：小规模或基本有序用插入；通用最快通常用快排（或 introsort）；需要稳定用归并；对最坏情况敏感用堆排；关键字范围有限且大基数用计数/基数。
